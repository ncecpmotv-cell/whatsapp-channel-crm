# سجل المصادر

عند: «سجّل المصادر» · قبل اعتماد خطة فيها أرقام.

## الميزانية
صفر استدعاءات (كتابة فقط).

## الخطوات
1. لكل منشور فيه رقم/خبر: `crm_post_pack {"id": ...}`.
2. جهّز كائن `sources`:
   ```json
   {"claims": [{"claim": "...", "url": "...", "checked_at": 0, "status": "confirmed|single|none"}]}
   ```
3. ادمجه في المنشور: `crm_update_channel_post {"id": ..., "meta": {...}}` — حافظ على
   `visual_brief` إن وُجد.
4. اطبع: عدد الادعاءات، وكم بلا مصدر.

## قواعد
- لا تحذف `visual_brief` أو `angle_id` من `meta` عند الدمج.
- لا تضع رابطًا لم تقرأه.
- المصادر جزء من المنشور لا ملاحظة جانبية.

## المخرجات
`post_id — ادعاءات: n — مؤكدة: n — بلا مصدر: n`
