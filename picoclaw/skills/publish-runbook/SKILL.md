# دليل النشر

يُستخدم عند: «وش جاهز للنشر؟» · «افحص المجدول» · «قبل ما ننشر».

## الميزانية

**صفر استدعاءات نموذج** في الفحص. القياس بعد النشر قراءة أرقام فقط.

## الفحص (قبل)

1. `crm_list_ready_posts` — المجدول/المستحق.
2. لكل منشور: `crm_lint_post {"id": ...}` وسجّل:
   - `error` (empty / media_missing) → **أوقف**: لا يصلح للنشر.
   - `warning` (too_long / duplicate / slot_collision / visual_brief_missing / brand_violation /
     off_palette) → اذكره مع سبب مختصر.
3. تحقق من التقارب الزمني: منشوران في أقل من ٣٠ دقيقة = تعارض.
4. اطبع جدولًا: `العنوان · الحالة · العوائق · الإجراء`.

## القياس (بعد ٢٤ ساعة)

1. `content_insights {"days": 7}` — متوسط المشاهدات والتفاعل.
2. `crm_post_pack` للمنشور المنشور — أرقامه الفعلية.
3. سطر واحد: هل تجاوز المتوسط أم لا، واقتراح **تجربة واحدة** فقط (وقت، طول، نوع، هوك).

## ما لا تفعله

- **لا تنشر ولا تجدول ولا تعتمد** — كلها بشرية، والأدوات سترفضك.
- لا تصلح نصًا بنفسك دون إذن؛ اقترح التعديل وانتظر.
- لا تحذف منشورًا فاشلًا؛ الفشل بيانات.

## المخرجات

```
جاهز: ٢ · متعثر: ١ (media_missing) · متعارض: ١ (نفس الفتحة)
التالي: أرفق صورة «X» ثم أعد الفحص
```
