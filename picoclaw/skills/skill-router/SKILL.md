# موجّه المهارات

عند: كل طلب جديد قبل تنفيذ أي شيء.

## الخطوات
اقرأ الطلب وحدّد مهارة واحدة (وأحيانًا اثنتين بترتيب):

| الطلب | المهارة |
|---|---|
| «وش في الوارد/رد» | reply-desk |
| «عنوان/هوك» | hook-lab أو title-formulas |
| «عندي فكرة/أبي…» | **orchestrator** (ثم ما يقترحه) |
| «خطة أسبوع» | editorial-board |
| «استراتيجية/٩٠ يوم» | strategic-plan |
| «حلّل المحتوى» | strategic-analysis |
| «ظهور/انتشار» | visibility-plan |
| «فسّر الأرقام» | insight-interpreter |
| «لمن نكتب» | audience-persona |
| «كاروسيل/شرائح» | carousel-builder |
| «حوّل منشورًا» | repurpose |
| «وزّع/لينكدإن» | distribution-plan / crosspost-adapter |
| «إطلاق/سلسلة» | launch-calendar / series-planner |
| «مراجعة/تسرّب» | weekly-review / retention-audit |
| «A/B» | ab-designer |
| «عرض/تسعير» | offer-builder |
| «تحقق/مصادر» | fact-check-lite / source-log |
| «تفاعل/تعاون» | community-prompts / collab-pitch |
| «صوت» | voice-desk |
| «أزمة/شكوى» | incident-comms |
| «قبل النشر» | publish-runbook |
| «هوية/ألوان» | channel-brand |
| «أرقام/تعريفها» | metrics-glossary |

## قواعد
- مهارة واحدة أولًا؛ لا تخلط ثلاث.
- إن لم تجد: قل «لا مهارة مناسبة» واقترح أقربها.
- حمّل المهارة (skills tool) قبل تنفيذ خطواتها، ولا تعتمد على الذاكرة.
