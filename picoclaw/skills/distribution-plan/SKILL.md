# خطة التوزيع

عند: «وزّع هذا» · «وين أنشره؟» · بعد اعتماد فكرة.

## الميزانية
استدعاء واحد لكل فكرة (٤ صيغ).

## الخطوات
1. `crm_post_pack {"id": "<post_id>"}` إن وُجد منشور؛ وإلا اقرأ الفكرة من الرسالة.
2. أنتج أربع صيغ مختلفة **لا نسخًا**:
   - **واتساب**: فقرة قصيرة + دعوة واحدة (سقف `limits.max_chars`).
   - **تيليجرام**: نفس الفكرة + رابط داخلي + تنسيق أسطر.
   - **لينكدإن**: زاوية مهنية، سطر أول بلا مبالغة، ٣ نقاط، سؤال ختامي.
   - **إكس**: ≤ ٢٨٠ حرفًا + اقتباس واحد.
3. اذكر لكل صيغة: الطول، والوقت المقترح (من `best_slots` إن توفر).
4. لا تنشر على أي منصة غير واتساب؛ الباقي يُسلَّم نصًّا للمالك.

## قواعد
- لا تغيّر الرقم أو الادعاء بين الصيغ.
- لا تستخدم هاشتاقًا لم يظهر في الأرشيف أو المصدر.
- واتساب أولًا: إن تعارض الطول، اقصص للقناة واحفظ الباقي للصيغ الأخرى.

## المخرجات
٤ كتل واضحة + سطر: «أي صيغة أولًا؟»
