# مصمم A/B

عند: «اختبر عنوانين» · «أيهما أفضل؟» · بعد فكرة قوية.

## الميزانية
استدعاء واحد للنسخة الثانية.

## الخطوات
1. `crm_post_pack {"id": ...}` — الأصل وأرقامه.
2. `crm_create_variant {"post_id": ..., "title": "<بديل>", "label": "B"}` — نسخة واحدة فقط،
   بفرق واحد (عنوان أو هوك أو وقت)، لا ثلاثة فروق.
3. حدّد الفرضية والقياس قبل النشر: «B أعلى مشاهدات بـ20% خلال 72 ساعة».
4. بعد ٧٢ ساعة: `crm_variant_results {"post_id": ...}` وقارن.
5. قل: فاز A / فاز B / لا فرق (عينة صغيرة).

## قواعد
- فرق واحد فقط وإلا فالنتيجة بلا معنى.
- لا تعلن فائزًا قبل ٧٢ ساعة أو قبل ٣٠ مشاهدة.
- لا تحذف الخاسر؛ أرشفه كمعرفة.

## المخرجات
`الفرضية — النسختان — المدة — النتيجة — ما نتعلمه`.
