# أدوات مجانية يمكن ربطها بـ PicoClaw

كل ما هنا **له طبقة مجانية فعلية** (لا تجربة فقط)، لكن الحدود تتغيّر — الأرقام أدناه من صفحات التسعير وقت الكتابة، والرابط هو المرجع. لا تعتمد على رقم بلا تحقق.

## البحث والقراءة (الأهم لخطط المحتوى)

| الخدمة | الطبقة المجانية | ملاحظة | الرابط |
|---|---|---|---|
| **Exa** | رصيد شهري (~$10) + رصيد ترحيبي، بدون بطاقة | أفضل من غيره للبحث الدلالي/الأفكار | https://exa.ai/pricing |
| **Firecrawl** | ~1,000 اعتماد/شهر، بدون بطاقة | ممتاز لتحويل صفحة إلى Markdown نظيف | https://www.firecrawl.dev/ |
| **Brave Search API** | رصيد شهري (~$5 ≈ 1,000 طلب) | نتائج ويب عامة، سريع | https://api-dashboard.search.brave.com/documentation/pricing |
| **Tavily** | رصيد مجاني شهري للمطوّرين | مصمّم لوكلاء LLM | https://docs.tavily.com/documentation/api-credits |
| **DuckDuckGo (HTML)** | بلا مفتاح إطلاقًا | غير رسمي وقد ينكسر؛ للاستخدام الخفيف فقط | https://duckduckgo.com/html/ |

**التوصية لهذا المشروع:** ابدأ بـ **Firecrawl** (قراءة صفحات) + **Exa** (أفكار). الأول يعطيك محتوى مرجعيًا نظيفًا، والثاني يعطيك زوايا جديدة. Brave يكفي إن أردت بديلًا أرخص للبحث العام.

## الصور (لوسائط المنشورات)

| الخدمة | المجاني | ملاحظة |
|---|---|---|
| **Pollinations** | توليد بلا مفتاح (بجودة وحدود متغيّرة) | جيد للتجربة فقط |
| **BFL / FLUX API** | رصيد ترحيبي | جودة عالية، مدفوع بعد الرصيد |
| **Gemini (Nano Banana / Imagen)** | طبقة مجانية محدودة | الحدود تغيّرت كثيرًا؛ تحقق قبل الاعتماد |
| **OpenRouter (مولّدات صور مجانية)** | بعض الموديلات `:free` | حدود صارمة، لكنه بلا تكلفة |

**قاعدة عملية:** لا تولّد صورة لكل منشور. صورة واحدة أصلية أفضل من عشر صور مولّدة؛ الجمهور يفرّق.

## النماذج (لعقل الوكيل)

| الخيار | المجاني | ملاحظة |
|---|---|---|
| **Gemini Flash-Lite (AI Studio)** | طبقة مجانية | كافية للتلخيص والتصنيف |
| **OpenRouter `:free`** | عدة موديلات | جيدة للتجربة، حدود يومية |
| **Ollama محلي** | مجاني تمامًا | يحتاج جهازًا قويًا؛ ليس على الجوال |
| **Ollama Cloud** | رصيد محدود | ما تستخدمه حاليًا (`deepseek-v4.1-flash`) |

**التوصية:** موديل مجاني/رخيص للمهام الروتينية، وموديل أقوى (مدفوع بالاستخدام) لجلسة التخطيط الأسبوعية فقط. الفرق في جودة الخطة يستحق.

## الربط في PicoClaw

```bash
# سيرفر HTTP بمفتاح
picoclaw mcp add firecrawl https://mcp.firecrawl.dev --transport http \
  --header "Authorization: Bearer $FIRECRAWL_API_KEY"

# سيرفر stdio عبر npx
picoclaw mcp add exa npx -y exa-mcp-server -e EXA_API_KEY=$EXA_API_KEY

picoclaw mcp test exa        # يسرد الأدوات قبل الاعتماد عليها
picoclaw mcp list            # ما هو مربوط الآن
```

كل سيرفر يضيف سطح أدوات — قيّده:

```json
"tools": { "include": ["search", "scrape"] }
```

## تكلفة الصفر: ما لا يحتاج مفتاحًا أصلًا

- **RSS**: خلاصات المواقع والمدونات تُقرأ بـ`curl`/Python بلا مفتاح.
- **صفحات عامة**: `web_extract`/`curl` + Firecrawl المجاني عند الحاجة لجافاسكربت.
- **بيانات القناة**: موجودة أصلًا في `crm.db` — استخدم `content_insights` و`posting_times` قبل أي خدمة مدفوعة.

## تحذير أمني

مفاتيح هذه الخدمات تُخزَّن في `.security.yml` (صلاحية 600) ولا تُذكر في محادثة أو لقطة شاشة. أي مفتاح يظهر في Git يجب اعتباره محروقًا ويُستبدل فورًا.
