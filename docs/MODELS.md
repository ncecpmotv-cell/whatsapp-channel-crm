# النماذج المجانية وإنضباط التوكنز

> كل رقم هنا **مقاس على الجهاز**، لا منقول من صفحة تسويق. التاريخ: 2026-11-28.

## المُهيَّأ الآن

- `default` — Ollama Cloud · `deepseek-v4.1-flash` — دور كامل بأداة: **5.4s**
- `fallback` — OpenRouter (free) · `baidu/ernie-5.5-flash-preview:free` — **7.3s**

التبديل: `picoclaw model fallback` · الرجوع: `picoclaw model default`.
المفاتيح في `~/pico/.security.yml` تحت `model_list.<name>:0.api_keys` بصلاحية `0600` — لا تُكتب
في المستودع ولا في الوثائق.

## قياسات حقيقية

- Ollama Cloud، استدعاء صغير («قل: جاهز»): **1.1 ثانية · 75 توكن**.
- OpenRouter بأداة `crm_inbox`: **1.4 ثانية · 177 توكن**، وأعاد `tool_calls` صحيحًا.
- دور وكيل كامل (قراءة الوارد ثم جواب): **5.4s** أساسي · **7.3s** بديل — كلاهما نفّذ أداة MCP واحدة.

## نماذج فُحصت ورُفضت

- `nvidia/nemotron-3.5-lightning:free` — لا يعيد `tool_calls` (غير صالح لوكيل أدوات).
- مفتاح Ollama Cloud الثاني أعاد `Add usage credits or subscribe` → لم يُثبَّت؛ العامل هو المفتاح
  الموجود أصلًا على الجهاز.

## ضبط إنضباط التوكنز (مطبَّق)

```
max_tool_iterations         = 16   (كان 50)
max_tokens                  = 8192 (كان 32768)
summarize_message_threshold = 12   (كان 20)
summarize_token_percent     = 60   (كان 75)
```

مع `crm_orchestrate` يصبح الدور النموذجي: **نداء أداة واحد + رد واحد**.

## سبع قواعد

1. **`crm_orchestrate` أولًا** — لا تجمع السياق بنفسك.
2. **لا تعد قراءة** `content_insights`/`content_gaps`؛ قيمها في الموجز.
3. **`crm_post_pack` بدل خمس أدوات** لمنشور واحد.
4. **مخرجات قصيرة**: جدول أو ثلاث جمل.
5. **استدعاء نموذج واحد لكل مهارة**.
6. **جلسة جديدة لكل مهمة** (`-s`) حتى لا يُعاد إرسال تاريخ طويل.
7. **الكرون موزّع**: 07:30 موجز · اثنين 10:00 خطة · الرادار كل ساعتين بلا نموذج.

## عند نفاد الطبقة المجانية

- الأساسي يفشل → `picoclaw model fallback`، أو أضف مزوّدًا:
  `picoclaw model add -b <base> -k <key> -n <name> --model <id>`.
- لا تعِد المحاولة بلا سقف: `max_tool_iterations=16` هو الحد.

## ما لا يفعله الوكيل مهما كان النموذج

- لا يعتمد ولا يجدول ولا ينشر (`AGENT_TOKEN` يُرفض بـ`-32003`).
- لا يتجاوز سقوف التكلفة: 40 استدعاء ذكاء على الحافة، 30 منشورًا، 20 رسالة/ساعة.

## القياس

`/ui/capabilities` يعرض النماذج والسيرفرات والمهارات وآخر التشغيلات. بعد أسبوع، قارن في
`content_insights` المنشورات المنجزة مقابل الأخطاء — هذا مؤشر «هل النموذج يكفي»، لا الانطباع.
