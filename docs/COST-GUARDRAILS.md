# قاعدة التكلفة — لا فاتورة، أبدًا

> **قاعدة المالك (٢٨ نوفمبر ٢٠٢٦):** المشروع لا يستخدم أي خدمة مدفوعة. كل ميزة سحابية تُصمَّم
> بسقوف صريحة ترفض الطلب عند بلوغها، ولا تعتمد على «حسن السلوك» أو على تذكّر أحد.

## أسعار Cloudflare المعنية (كما وردت من المالك)

| البند | السعر بعد الطبقة المجانية |
|---|---|
| R2 Storage | $0.015 / GB-month |
| Class A operations (كتابة/قائمة/حذف) | $4.50 / مليون |
| Class B operations (قراءة) | $0.36 / مليون |

الطبقة المجانية: **10GB تخزين · مليون Class A · عشرة ملايين Class B شهريًا**، والتصدير (egress) مجاني.
Workers AI: **10,000 neurons يوميًا**.

## السقوف المفروضة في الكود

كلها في `edge/src/ops.js` (`BUDGET`) وتُقرأ من `wrangler.toml`:

| المتغير | القيمة | ماذا يمنع |
|---|---|---|
| `KEEP_BACKUPS` | 3 | احتفاظ غير محدود: آخر 3 نسخ فقط، والأقدم يُحذف فورًا |
| `MAX_BACKUP_MB` | 8 | نسخة واحدة ضخمة (النسخة الفعلية ~40KB) |
| `MAX_TOTAL_MB` | 64 | مجموع التخزين: رفض `507` قبل الكتابة |
| `AI_DAILY_LIMIT` | 40 | استدعاءات Workers AI في اليوم: رفض `429` |

الرفض دائمًا صريح: `{"error": "...", "limit": true}` مع رمز `413` / `429` / `507` — لا تحذير يُتجاهل.

## الحساب

- **التخزين:** 64MB سقف مطلق مقابل 10GB = **0.6%** من الطبقة المجانية. الاستخدام الفعلي الآن
  **0.05MB** لثلاث نسخ.
- **Class A:** رفع واحد = `put` + `list` + `delete` ≈ 3 عمليات. نسخة يومية = ~90 شهريًا مقابل
  مليون = **0.009%**.
- **Class B:** تنزيل نسخة عند الاستعادة فقط.
- **AI:** 40 استدعاء × 30 يومًا = 1200 شهريًا؛ حملة واحدة عادية تكفي، والفائض مرفوض.

## قواعد أي ميزة سحابية قادمة

1. **سقف مكتوب قبل الكود.** كل ميزة تذكر في صفحتها: البند المجاني، الاستهلاك لكل استخدام،
   والسقف الذي تفرضه.
2. **عدّاد ورفض.** لا يكفي «نتوقع أن يبقى قليلًا»: عدّاد في KV (أو ما يعادله) ورمز رفض صريح.
3. **لا احتفاظ بلا حد.** كل ما يُخزَّن له سياسة دوران (عدد أو حجم أو عمر) تُنفَّذ آليًا.
4. **لا `list` في مسار صفحة.** القوائم عمليات Class A؛ الصفحة تقرأ من KV، والقائمة الحيّة في
   مسار صريح فقط (زر أو أداة).
5. **الحقيقة من المصدر القوي.** قرارات الحذف تُبنى على `R2.list` (متسق بقوة) لا على KV
   (متسق نهائيًا) — قراءة KV قديمة حذفت النسخ الحديثة بدل القديمة في أول تنفيذ.
6. **`/usage` هو لوحة القيادة.** كل Worker يعرض استهلاكه: النسخ، الحجم، استدعاءات الذكاء،
   والحدود — و`/ui/edge` على الجوال يعرضها بالعربي.
7. **الاختبار يثبت الرفض.** اختبار `507` و`429` جزء من الحزمة، لا تجربة يدوية.

## أين تُرى

- `/ui/edge` على الجوال: «نسخ محفوظة 3/3» · «مساحة مستخدمة 0.05/64 MB» · «استدعاءات الذكاء 1/40».
- `GET /usage` على الـWorker (يتطلب التوكن).
- `/status` العامة تعرض عدد النسخ فقط، بلا أرقام تكلفة.
