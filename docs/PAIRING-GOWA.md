# اقتران واتساب عبر GOWA (من الجوال إلى النظام)

هذا الدليل يشرح كيف يُربط رقم واتساب بالمنظومة، وأين تُمسح الشيفرة، وماذا تفعل عندما ينقطع الاقتران.

> الاقتران يتم مرة واحدة لكل جهاز. الحالة تُحفظ في مجلد GOWA (`~/.whatsapp-crm/gowa/`)، وإعادة تشغيل الجوال أو النظام لا تحتاج شيفرة جديدة — إلا إذا خرجت من «الأجهزة المرتبطة» في واتساب نفسه.

## ١) قبل أن تبدأ

- واتساب مثبّت على الجوال ومربوط برقمك.
- النظام يعمل: `~/.whatsapp-crm/bin/crmctl status` يجب أن يُظهر `gowa` و`crm` بحالة تشغيل.
- إن كنت تُشغّل على جوال آخر (Termux)، افتح الرابط من ذلك الجوال؛ وإلا استخدم `tailscale serve` للوصول من جهازك.

## ٢) اطلب شيفرة الاقتران

```bash
bash scripts/install.sh --qr
```

تُحفظ الشيفرة في `~/.whatsapp-crm/var/whatsapp-qr.png`. افتحها على شاشة الجوال الذي سيمسحها.

بديل مباشر من المتصفح:

```bash
# من نفس الجهاز أو عبر نفق
xdg-open http://127.0.0.1:3000        # واجهة GOWA المدمجة
```

> الشيفرة صالحة ~30 ثانية وتتغيّر. إن انتهت، أعد طلبها.

## ٣) امسحها من واتساب

1. واتساب على الجوال → **الإعدادات** → **الأجهزة المرتبطة**.
2. **ربط جهاز**.
3. وجّه الكاميرا إلى الشيفرة.

تظهر رسالة «تم ربط الجهاز». تحقّق من الطرف الآخر:

```bash
curl -u crm:$(grep '^GOWA_PASSWORD=' ~/.whatsapp-crm/etc/gowa.env | cut -d= -f2-) \
     http://127.0.0.1:3000/app/devices
```

يجب أن يظهر جهاز واحد بحالة `logged_in` والرقم المقنّع.

## ٤) اربط القناة بالنظام

بعد الاقتران، انسخ معرّف القناة (JID) إلى الإعدادات:

```bash
# etc/crm.env
NEWSLETTER_JIDS=1203xxxxxxxxxxxxxx@newsletter
```

كيف تجد المعرّف؟

```bash
curl -s -u crm:$GOWA_PASSWORD http://127.0.0.1:3000/newsletter | python3 -m json.tool | head -40
```

أو من داخل التطبيق: تبويب **القناة** → «مزامنة أرشيف القناة».

ثم:

```bash
~/.whatsapp-crm/bin/crmctl restart
```

## ٥) ماذا يحدث بعد الاقتران

| الشيء | السلوك |
|---|---|
| منشورات القناة السابقة | تُستورد تلقائيًا عند الإقلاع (ومرّة كل 5 دقائق) |
| القياسات (مشاهدات/تمرير/تفاعل) | تُحدَّث من GOWA وتُحفظ لقطة يومية |
| رسائل الخاص | تصل عبر webhook موقّع وتُنشئ عميلًا/إشعارًا |
| النشر | يخرج من النظام عبر GOWA بعد اعتمادك |

## ٦) عندما ينقطع الاقتران

| العرض | السبب | الحل |
|---|---|---|
| الإرسال يفشل بخطأ 401 | الجلسة انتهت (خروج من الأجهزة المرتبطة، تغيير جوال) | أعد الاقتران: `install.sh --qr` |
| `gowa` لا يستجيب | العملية توقفت | `crmctl start` ثم افحص `var/log/gowa.log` |
| الشيفرة لا تظهر | GOWA غير مصادَق بعد | استخدم `-u crm:$GOWA_PASSWORD` مع `/app/login` |
| «logged out» في السجل | واتساب رفض الجلسة | امسح الجهاز من واتساب ثم أعد الربط |

**مهم:** إعادة الاقتران لا تمسّ بياناتك — المنشورات والعملاء والقياسات في `crm.db`، والاقتران يتعلق بالجلسة فقط.

## ٧) أمان

- لا تشارك صورة الشيفرة: من يمسحها يملك جلسة واتساب كاملة.
- GOWA يستمع على `127.0.0.1` فقط؛ لا تفتح المنفذ 3000 للشبكة.
- كلمة مرور GOWA موجودة في `etc/gowa.env` بصلاحية 600.
- عند فقدان الجوال: من واتساب → الأجهزة المرتبطة → امسح جهاز GOWA، ثم أعد الاقتران من الجهاز الجديد.
