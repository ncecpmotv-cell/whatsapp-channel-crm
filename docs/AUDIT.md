تاريخ التدقيق: 2026-11-26 · النطاق: `bridge/` (4553 سطرًا)، `scripts/`، الواجهة، الأمان، الأداء، المحتوى.
إعادة التشغيل: `BASE=http://127.0.0.1:8085 bash scripts/audit.sh` (‏17 فحصًا، آخر نتيجة **17/17**).

## المنهج

1. فحص ثابت: `compileall`، بحث عن أنماط خطرة (`eval/exec/shell=True/pickle`)، ومسح أسرار.
2. اختبارات: 14 اختبار وحدة + 19 فحص e2e عبر HTTP حقيقي (GOWA وهمي).
3. أمان HTTP: مصادقة كل مسار، تسريب التوكن، CSRF، ترويسات الأمان، رفع الملفات.
4. واجهة: لقطات 360px + فحص نصي لكل مسار (‏`verify_routes.sh`، صفر `NaN/undefined`).
5. أداء: Lighthouse mobile (360×640@3x · CPU ×4 · Slow 4G) على 4 صفحات.

## مؤجّل بقرار (غير منفّذ)

- **لا رمز CSRF لكل نموذج**: الاعتماد على `Sec-Fetch-Site` + `Origin` + Basic؛ كافٍ داخل tailnet، ويُستأنس برمز عند فتح الوصول لشبكة أوسع.
- **تقليل الصور المصغّرة في القوائم**: المعاينة موجودة في صفحة المنشور فقط؛ إضافة مصغّرات للبطاقات تتطلب طلبات صور إضافية (تأجيل بأثر واضح).
- **CSP يسمح `style-src 'unsafe-inline'`**: لأن التنسيقات تُكتب كخصائص `style` داخل القوالب؛ إزالتها تتطلب نقلها إلى CSS.
- **لا مدقّق أنواع (mypy/ruff)**: غير مثبّتة في البيئة؛ الفحص الحالي يغطي الترجمة والاختبارات والأنماط الخطرة.
